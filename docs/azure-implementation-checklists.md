# Azure Support Implementation Checklists

These checklists define the Azure scope for CloudMock's multi-cloud refactor. They start from the Azure documentation hub and prioritize the Azure services and platform features needed to map CloudMock's current AWS-focused behavior onto Azure Resource Manager, Azure data-plane APIs, and Azure SDK/CLI workflows.

Each item links to Microsoft Learn documentation that should be used while implementing and testing the feature.
